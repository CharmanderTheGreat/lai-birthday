# Birthday Web Card for a Friend

A personalized, interactive digital birthday card created for a friend, hosted on GitHub Pages.

---

## Features

- **Passcode Lock Screen:** Secret PIN keypad required to open the birthday surprise.
- **Birthday Letter:** Scrollable greeting message and letter view.
- **Surprise Media Reveal:** Full-view picture showcase unlocked after the letter.
- **Interactive Birthday Cake:** Blowable candle flames with smoke effects, sound, and a relight option.
- **Celebration Effects:** Confetti particle showers and built-in sound chimes.
- **Encrypted Single File:** Message, photos, and code are bundled into one standalone file to keep contents private.

---

## Tech Stack

| Tool | Usage |
| :--- | :--- |
| **HTML5 & JavaScript (ES6+)** | Screen transitions, input verification, and interaction logic |
| **Tailwind CSS & CSS3** | Visual styling, responsive layout, and candle/smoke animations |
| **Web Audio API** | In-browser synthesized sound effects (no external audio files needed) |
| **Canvas Confetti** | Confetti blast animations |
| **Google Fonts** | Custom web typography |
